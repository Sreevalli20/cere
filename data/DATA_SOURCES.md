# Data Sources

## Included Demonstration Data

### demo_conversation.csv

**Status:** SYNTHETIC DEMONSTRATION DATA

The included demonstration conversation in `data/demo_conversation.csv` is **synthetic and is provided only to demonstrate the application pipeline**.

**Purpose:**
- Demonstrates the ToneTrace analysis pipeline
- Shows the progression from calm → disagreement → frustration → sarcasm → passive aggression → escalation → de-escalation
- Enables users to test the application without providing their own data

**Disclaimer:**
- No claim is made that this represents a benchmark dataset
- No claim is made that this represents real conversations
- This is not training data
- This is not a validated dataset
- Results on this data should not be used as performance metrics

**Generation:**
- Generated programmatically in `src/demo.py`
- Designed to showcase the temporal analysis capabilities
- Not sourced from any external dataset
